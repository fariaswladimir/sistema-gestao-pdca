2. Garanta dados de demonstração com `make seed` (setor piloto fictício, sem dados pessoais reais).
3. Escreva `specs/Fxx-*/demo.md` com: objetivo, perfil usado em cada passo, passos (máximo 8), o que o usuário deve ver,
   e as perguntas de feedback para o usuário.
4. Execute o roteiro no navegador do Antigravity e capture screenshots de cada passo.
