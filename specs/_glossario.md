# Glossário

| Termo | Definição |
| --- | --- |
| Ciclo | Período de gestão com objetivos e metas (ex.: 2027). |
| Objetivo estratégico | Resultado que a organização quer alcançar, ligado a uma perspectiva do mapa estratégico (Clientes, Finanças, Processos, Pessoas). |
| Indicador | Medida com fórmula, unidade, periodicidade e meta. É um nó da árvore de desdobramento. |
| Árvore de desdobramento | Hierarquia objetivo → indicador estratégico → setor → time → individual. |
| Tipo de indicador | Classificação em 5 dimensões: nível, natureza, polaridade, consolidação, origem. |
| Item de controle | Indicador de resultado; é cobrado. |
| Item de verificação | Indicador de causa ou processo; explica o item de controle. |
| Polaridade | maior_melhor, menor_melhor ou faixa (entre mínimo e máximo). |
| Consolidação | Como os filhos compõem o pai: soma, media, media_ponderada, ultimo, nenhuma. |
| Medição | Valor de um indicador em um período. |
| Farol | Situação do indicador no período: verde, amarelo, vermelho, sem_dado. |
| Tolerância | Faixa que define amarelo. [SUPOSIÇÃO] padrão 5% da meta, configurável por indicador. |
| Aceite de meta | Confirmação formal da meta pelo responsável e pelo gestor. |
| Anomalia | Registro de resultado fora do alvo (ou problema na rotina) que exige análise de causa. |
| 6M | Categorias da espinha de peixe: método, máquina, mão de obra, material, medida, meio ambiente. |
| Causa raiz | Causa marcada como origem principal da anomalia. |
| Plano de ação | Conjunto de ações com responsável e prazo para eliminar a causa raiz ou atingir a meta. |
| Verificação de eficácia | Checagem, após o plano, se o indicador voltou ao alvo. |
| POP | Procedimento Operacional Padrão de uma tarefa crítica. Base do SDCA. |
| DTO | Diagnóstico do Trabalho Operacional: verificação se o POP é seguido. |
| Lição aprendida | Conhecimento registrado ao fechar uma anomalia. |
| SDCA | Ciclo de manutenção: padrão, execução, verificação, correção. |
| PDCA | Ciclo de melhoria: planejar, executar, verificar, agir (padronizar). |
| Ritual | Reunião com cadência: Bom Dia, reunião de resultados, Cumbuca, feedback. |
| Pauta por exceção | Pauta gerada só com o que está fora do padrão. |
| Diagnóstico da gestão | Avaliação periódica da prática do método por setor, com itens e nota. |
| Índice de execução da gestão | Indicador estratégico alimentado pela média das notas do diagnóstico. |
| Setor | Unidade organizacional (área, núcleo, gerência, regional), com setor pai. |
| Rascunho | Estado de algo criado por regra ou IA que precisa de aprovação humana. |
