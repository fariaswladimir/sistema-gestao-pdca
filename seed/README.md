# Seed

Dados fictícios para desenvolvimento e demonstração. Nenhum dado pessoal real.

- `app/seed` (criado na F00) gera: setores Sede > Piloto/Outro, colaboradores por perfil (ana, bruno, carlos, duda, eva, root),
  tipos de indicador, um ciclo, objetivos e indicadores com 12 meses de histórico.
- `planilhas/`: exemplos anonimizados no formato "Indicadores Operacionais" (uma aba por setor) para a importação da F10.
  Gere a partir das planilhas reais trocando nomes por "Colaborador 01", "Colaborador 02"...
